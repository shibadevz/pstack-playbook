# ปล่อยรันเอง/ข้ามคืน

ใช้เมื่อจะเดินไปไหนแล้วให้ agent ทำต่อเองจนเสร็จ และกลับมาตรวจทีหลัง หน้านี้อ่านได้โดยไม่ต้องใช้ database

## เริ่มจากสิ่งเหล่านี้ (เรียงตามลำดับ)

1. **Playbook: Autonomous run** — ตั้ง done เป็น check ที่ผ่านหรือไม่ผ่านได้ แล้วขับจนถึงเงื่อนไขนั้นโดยไม่หยุด. วิธีเรียก: พิมพ์ `/pstack:poteto-mode im going to bed. <goal>. done means <checks>.`
2. **/pstack:show-me-your-work** — เก็บ decision log เป็น TSV ให้ตรวจตอนเช้า เริ่มจากหัวข้อ Attention ท้าย reply. วิธีเรียก: พิมพ์ `/pstack:show-me-your-work`
3. **/pstack:ketchup** — กลับมาแล้วอยากรู้สั้นๆ ว่าอะไรเปลี่ยนและอะไรรอให้ตัดสินใจ. วิธีเรียก: พิมพ์ `/pstack:ketchup`
4. **Playbook: Pause safely** — ต้องหยุดชั่วคราว (offline หรือ context ใกล้ compact) โดยให้งานต่อได้. วิธีเรียก: พิมพ์ `/pstack:poteto-mode pause safely.`
5. **Playbook: Session pickup** — รับช่วงงานที่ agent อีกแชตทำค้างไว้จาก transcript หรือ branch. วิธีเรียก: พิมพ์ `/pstack:poteto-mode take over this branch.`

## ตัวอย่าง prompt

```text
/pstack:poteto-mode ฉันจะไปนอนแล้ว migrate ทุก caller ไปใช้ parser ใหม่ ใน worktree ใหม่ที่แตกจาก main done คือไม่เหลือ caller เก่า parser fixture ผ่านทั้งหมด และ API เก่าถูกลบ เก็บ decision log ไม่ต้องถามก่อน commit ถ้าติดจริงๆ หลังผ่านไปหลายชั่วโมง ให้หยุดแล้วเขียนสรุปว่าทำไม
```

เขียน prompt โดยบอก goal และ done check ที่ตรวจได้ ไม่ต้องไล่ชื่อ skill เอง ให้ `/pstack:poteto-mode` เลือกขั้นตอน
