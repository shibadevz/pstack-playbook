# เขียนเอกสาร/สื่อสาร

ใช้เมื่อต้องเขียนหรือเล่าให้คนอ่านเข้าใจ เช่น docs, PR description หรือ reply ของ agent หน้านี้อ่านได้โดยไม่ต้องใช้ database

## เริ่มจากสิ่งเหล่านี้ (เรียงตามลำดับ)

1. **/pstack:technical-writing** — มาตรฐานเขียน docs, RFC, README, PR description และ commit message. วิธีเรียก: พิมพ์ `/pstack:technical-writing`
2. **/pstack:unslop** — ตัวคำและรูปประโยคที่ดูเหมือน AI เขียนออกจากข้อความ. วิธีเรียก: พิมพ์ `/pstack:unslop`
3. **/pstack:bro** — ให้ agent เล่า reply ล่าสุดใหม่เป็นภาษาคนธรรมดาและสั้นลง. วิธีเรียก: พิมพ์ `/pstack:bro`
4. **/pstack:ketchup** — สรุปสิ่งที่เปลี่ยนในแชตตั้งแต่ข้อความล่าสุดของคุณ. วิธีเรียก: พิมพ์ `/pstack:ketchup`

## ตัวอย่าง prompt

```text
/pstack:technical-writing เขียนหัวข้อ README ที่อธิบายวิธีรันคำสั่ง export แล้ว /pstack:unslop อีกรอบ
```

เขียน prompt โดยบอก goal และ done check ที่ตรวจได้ ไม่ต้องไล่ชื่อ skill เอง ให้ `/pstack:poteto-mode` เลือกขั้นตอน
