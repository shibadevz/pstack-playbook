# /pstack:bro

<small>ประเภท: **Workflow skill** · สถานการณ์: `เขียนเอกสาร/สื่อสาร`</small>

## ใช้ทำอะไร

เล่าข้อความล่าสุดของ agent ใหม่เป็นภาษาคนธรรมดา สั้นลง ไม่มี jargon

## ใช้เมื่อ

เช่นเมื่อ reply ละเอียดครบแต่อ่านแล้วยังไม่รู้ว่าสรุปว่าอะไร

## ต่างจาก / ข้อควรรู้

bro เล่า reply ล่าสุดใหม่ ส่วน ketchup สรุปสิ่งที่เปลี่ยนในแชตตั้งแต่ข้อความล่าสุดของผู้ใช้

## วิธีเรียก

`/pstack:bro`

## ตัวอย่าง prompt

```text
/pstack:bro
```
