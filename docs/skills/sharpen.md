# /pstack:sharpen

<small>ประเภท: **Workflow skill** · สถานการณ์: `เริ่มงาน/ตั้งค่า` `ออกแบบ/วางแผน`</small>

## ใช้ทำอะไร

ยกระดับงานก่อนเริ่ม: ถามว่าผู้เชี่ยวชาญจะทำอย่างไร ผู้ใช้ต้องการอะไรจริงๆ และ spec ละเอียดพอดีหรือเกินไป พร้อมคลายข้อจำกัดที่ไม่ช่วยเป้าหมาย

## ใช้เมื่อ

เช่นเมื่อมี task คลุมเครือหรือ spec เกินจนจำกัด agent เช่น "รวม data จากสามแหล่งเป็นรายงาน"

## ต่างจาก / ข้อควรรู้

ต่างจาก in-your-own-words ที่ตรวจแค่ว่า agent เข้าใจเป้าหมายหรือไม่ sharpen ปรับตัวงานให้ตั้งเป้าสูงขึ้นและไม่ระบุเกิน

## วิธีเรียก

`/pstack:sharpen <งาน>`

## ตัวอย่าง prompt

```text
/pstack:sharpen build a weekly report that merges the sales, support and billing exports
```
