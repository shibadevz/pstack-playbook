# /pstack:in-your-own-words

<small>ประเภท: **Workflow skill** · สถานการณ์: `เริ่มงาน/ตั้งค่า`</small>

## ใช้ทำอะไร

ให้ agent เล่าด้วยคำของตัวเองว่าเข้าใจเป้าหมายและปัญหาของผู้ใช้ว่าอะไร

## ใช้เมื่อ

เช่นเมื่อได้รับ thread ยาวและรก แล้วอยากรู้ว่า agent อ่านผิดหรือไม่ก่อนมีโค้ดเกิดขึ้น

## ต่างจาก / ข้อควรรู้

ตรวจแค่ความเข้าใจ ไม่ทำงาน ถ้าอยากยกระดับตัวงานก่อนเริ่มให้ใช้ sharpen

## วิธีเรียก

`/pstack:in-your-own-words`

## ตัวอย่าง prompt

```text
/pstack:in-your-own-words <paste the long or messy ask here>
```
