# /pstack:principle-exhaust-the-design-space

## ใช้ทำอะไร

เมื่อเจอ interaction ใหม่หรือการตัดสินใจเชิงสถาปัตยกรรมที่ไม่มีแบบอย่างใน codebase ให้ build prototype 2-3 แบบที่แข่งกันแล้วเทียบข้างกันก่อนตัดสินใจ

## ใช้เมื่อ

เช่นเมื่อต้องเลือกว่าหน้า settings ควรเป็น tab, sidebar หรือ accordion และไม่มีแบบเดิมให้ยึด

## ต่างจาก / ข้อควรรู้

playbook Prototype คือวิธีทำหลักการนี้ให้ถูกและเร็ว
