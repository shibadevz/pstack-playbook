# /pstack:principle-experience-first

<small>ประเภท: **Principle** · สถานการณ์: `ออกแบบ/วางแผน` `สร้างฟีเจอร์`</small>

## ใช้ทำอะไร

เมื่อต้องแลก product, UX หรือขอบเขตฟีเจอร์ ให้เลือกความพอใจของผู้ใช้เหนือความสะดวกของ implementation และส่งฟีเจอร์น้อยแต่เนี้ยบ ดีกว่ามากแต่หยาบ

## ใช้เมื่อ

เช่นเมื่อมีเวลาพอทำแค่หนึ่งในสองอย่าง ระหว่างตัวกรองเดียวที่ลื่นกับตัวกรองห้าแบบที่กระตุก

## วิธีเรียก

`ส่วนใหญ่สั่งด้วยชื่อใน poteto-mode เช่น "apply experience first" หรือโหลดตรงด้วย /pstack:principle-experience-first`

## ตัวอย่าง prompt

```text
/pstack:poteto-mode we can ship either one polished filter or five rough ones. apply experience first and recommend one.
```
